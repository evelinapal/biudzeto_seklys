# 💰 Asmeninių Finansų Seklys (Budget Tracker)

Studento projektas, skirtas sekti asmenines pajamas bei išlaidas, valdyti kategorijas ir matyti bendrą finansinį balansą realiuoju laiku.

## 🌐 Nuoroda į veikiančią aplikaciją
- **Live Demo:** [https://biudzeto-seklys.vercel.app/](https://biudzeto-seklys.vercel.app/)

## 🚀 Naudojamos technologijos
- **Front-end:** React, Vite, JavaScript, HTML, CSS
- **Duomenų bazė ir Backend:** Supabase (PostgreSQL)
- **Versijų kontrolė:** Git & GitHub
